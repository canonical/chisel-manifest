# Chisel Manifest

This repository is a mirror of the `manifest`, `jsonwall` and the
`apachetestutil` modules from [Chisel's
repository](https://github.com/canonical/chisel). Even though these modules are
licensed under Apache-2.0 in the original repository, some projects had trouble
importing it because of the top level license.

This whole repository is licensed under [Apache-2.0 license](LICENSE) to make it
easier for other project to import these module. However, it is still preferred
to use the modules from [Chisel's
repository](https://github.com/canonical/chisel), which will remain to be the
source of truth.

All bug reports and security issues should still be reported through the [issues
page](https://github.com/canonical/chisel/issues) and the [security
advisory](https://github.com/canonical/chisel/security/advisories) in [Chisel's
repository](https://github.com/canonical/chisel).

This repository currently tracks the release
[`v1.2.0`](https://github.com/canonical/chisel/releases/tag/v1.2.0)

# Documentation

The documentation regarding Chisel and its manifest can be found in [Chisel's
documentation](https://documentation.ubuntu.com/chisel/en/latest/reference/manifest/).
